# Documentación de Urbox

Bienvenido a la documentación de **Urbox**, el CRM para WhatsApp.

Aquí encontrarás guías paso a paso pensadas para equipos de negocio: cómo conectar tu WhatsApp, configurar la IA, organizar conversaciones y sacar provecho de tus datos.

## Primeros pasos

- [Configuración de agentes IA](./guias/configuracion-agentes-ia) — cómo activar la IA, entrenarla con tu información y probarla antes de que responda a clientes.
- [Crear una automatización para tomar pedidos](./automatizacion-tomar-pedido) — ejemplo paso a paso de una automatización que recibe un pedido y lo registra en el embudo.

## Cómo está organizada

Cada guía es independiente y se puede leer en orden o consultar por tema. Si eres nuevo, empieza por la guía de configuración de agentes IA.

:::tip ¿Buscas algo concreto?
Usa el buscador de la barra superior o el menú lateral para ir directo a un tema.
:::

## Añadir nueva documentación

Las guías viven en el repositorio, en `docs-site/docs/`. Para publicar una nueva:

1. Crea un archivo Markdown con un título.
2. Sigue el formato de las guías existentes.
3. Abre un pull request. Al integrarse en `main`, el sitio se publica automáticamente.
